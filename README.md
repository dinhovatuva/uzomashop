# uzomashop
Uzomashop é uma plataforma digital angolana que possibilita aos residentes fazer compras de produtos diversos sem ter que se deslocar.

O presente projecto foi criado com php 7.2 usando a arquitetura MVC + DAO, forma utilizados no front HTML 5, CSS, JS

A DAO está na pasta em vendor\core\php-classes\src\DB ficheiro SQL.php

Para o uso do Recaptcha V2, deve colocar a chave privada na Classe Recaptcha.php em vendor\core\php-classes\src

Nota: Este projecto não é compativel com versões abaixo do Php 7 nem a versão 8, devido o framework Slim usado para criar rotas sendo necessário atualiza-lo para usar a versão 8 ou superior.
